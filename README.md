# Campus Buddy

Quick calculators for KTU students — attendance % tracker with leave planning, and internal marks calculator for series tests.

**Live:** https://campus-buddy.onrender.com

Built with Django. No login required — free to use by anyone.

## Features
- Attendance calculator with "safe bunks" and recovery math
- Plan-ahead: see your % if you skip upcoming classes
- Internal marks calculator (Series Test 1 + 2)
- Help page with usage notes
